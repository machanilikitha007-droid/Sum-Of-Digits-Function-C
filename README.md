# Sum of Digits Using Function in C

This program uses a function to calculate and return the sum of all
digits in a number.

## File

sum_digits.c

## Concepts Used

- Function return value
- Function parameter
- Function call
- while loop
- Modulus operator

## How to Run

gcc sum_digits.c -o sum_digits
./sum_digits

## Sample Output

Enter a number: 12345
Sum of digits = 15
